# Description
Ceci est un repository hébergeant différentes versions de tests en cours ou fini de Elrah-API

## Installation

- **Avec Github :**
  ```bash
  git clone https://github.com/Harrlequelrah/elrahapi-testproject
  ```

## Utilisation

- **Se rendre dans le repertoire du projet** :

```bash
  cd elrahapi testproject
```

-  **Création d'un environnement virtuel :**
```bash
  python -m venv env
```
ou
```bash
  virtualenv env
```

-  **Installation des dépendances :**
```bash
  pip install -r requirements.txt
```

-  **Initialisation des variables d'environnement :**
```bash
  cp .env.example .env
```

-  **Initialisation d'alembic (Optionnel) :**
```python
  alembic init alembic
```


- **Lancement du serveur :**
```python
  elrahapi run
```

## `Technologies et bibliothèques`

- Python
